# 🚬 Smoker - 올바른 흡연 문화를 위한 위치 기반 흡연 구역 안내 서비스
**Smoker**는 위치 기반 정보를 활용하여 사용자에게 흡연 구역 정보를 편리하게 제공하는 안내 서비스입니다.<br>
사용자는 지도를 통해 주변 흡연 구역을 직관적으로 검색하고, 목록에서 원하는 장소를 쉽게 찾을 수 있습니다.<br>
정확한 위치, 시설 옵션 정보, 이용 가능 시간 등을 제공해 불필요한 이동을 최소화하며, OCR 기능을 활용해 직접 흡연 구역을 등록할 수도 있습니다.<br>
Smoker는 흡연자와 비흡연자가 공존할 수 있는 환경을 만들기 위해 노력하겠습니다. ✨

## 📌 주요 기능

### 1. **흡연 구역 탐색 기능**

- **지도형 & 목록형**으로 사용자가 흡연 구역을 쉽게 찾을 수 있는 기능.
- **사용자 위치 기반 근처 흡연 구역 표시**: GPS를 이용해 현재 위치를 기반으로 주변의 흡연 구역을 지도상에 표시.
- **검색 필터링**: 실내/실외 흡연 구역 등의 필터를 제공하여 사용자가 원하는 조건에 맞는 흡연 구역을 검색.

### 2. **흡연 구역 정보 및 리뷰 열람 기능**

- **상세 정보 수정 및 열람**: 사용자가 찾은 흡연 구역의 상세 시설 정보 확인 및 수정 기능.
- **리뷰 작성 및 열람**: 이용자들이 리뷰를 작성하고 열람할 수 있는 기능.
- **SNS 공유 기능**: 흡연 구역 정보를 SNS에 공유할 수 있는 기능.

### 3. **흡연 구역 등록 기능**

- 사용자가 **흡연 구역을 직접 등록**할 수 있는 기능.
- **AI 자동화**: OCR을 통해 이미지에서 흡연 구역을 자동으로 인식하고 등록할 수 있는 기능.
- **사용자 이미지 업로드**: 입간판, 스티커 등 흡연 구역을 나타내는 이미지 업로드 후 AI가 이를 처리.

### 4. **흡연 구역 저장 기능**

- 사용자가 **흡연 구역 정보를 개인 보관함에 저장**할 수 있는 기능.
